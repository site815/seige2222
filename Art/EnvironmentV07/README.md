# Scenery distance proxies — v0.7

Status: the v0.7 Shipping revision is verified. Source-derived tree proxies and the grass proxy passed quantitative source-color, bounds, and material-slot validation. Rendered review accepted the replacement shapes and darker palette as an incremental improvement; distant low-detail silhouettes remain recognizable. This is not reference-game visual parity. The [graphics report](../../docs/game-design/GRAPHICS_PERFORMANCE_0_7.md) records native and 1600×900 measurements, moving-camera results, and the lower-resolution boundary-view regression.

Grass is original project geometry. Tree proxies derive from the retained CC0 source leaf distribution and woody structure. Their rendered surfaces use opaque geometry, without dither fades, billboards, or world-position-offset wind. Existing photographic materials and source attribution are retained.

The [deterministic entry point](../../Tools/prepare_scenery_lods_v07.py) runs in Blender without downloading assets. It generates grass, then invokes the [source-canopy generator](../../Tools/prepare_source_canopies_v07.py), which samples actual leaf vertices, forms an occupancy surface, and retains simplified real trunks/branches. Small twig faces below 25 cm² are omitted behind the crown surface. Editable sources are [grass](Source/Scenery_LODs.blend), [broadleaf](Source/SM_BroadleafProxy.blend), and [conifer](Source/SM_ConiferProxy.blend); the [manifest](proxy_manifest.json) records dimensions, triangle counts, provenance, and hashes. Prepare the near Jacaranda derivative first when rebuilding from source. The [Unreal importer](../../Tools/import_scenery_lods_v07.py) writes only `/Game/Art/NatureV07`, reuses existing photographic bark materials, and enables Nanite area preservation. The [import report](proxy_import_report.json) confirms the imported revision. Counts describe source assets, not per-frame rendered geometry or measured savings.

The opaque materials expose `MeanAlbedo`, `GrassTint`, and `CanopyTint`. Grass uses two-sided foliage shading; closed crowns use one-sided Default Lit shading with outward normals. Their instances are `MI_GrassProxy`, `MI_CanopyProxy`, and `MI_ConiferProxy`. The palette is informed by [measured linear colors](source_color_measurements.json) from existing foliage textures, considering pixels above the near material's alpha threshold and retaining its existing tint. Explicit mean albedos prevent missing runtime vertex colors from bleaching foliage; vertex green can change brightness only within 0.85–1.15. Crowns reuse the retained CC0 Jacaranda/fir leaf color and normal maps for bounded surface variation. Their alpha maps control that variation, never opacity.

The [authoritative linear palette](proxy_palette.json) sets grass to (0.10, 0.15, 0.045), broadleaf to (0.045, 0.080, 0.022), and conifer to (0.040, 0.060, 0.018). The tree values were reduced after a rendered review showed bright distant crown tops against darker near foliage. The [palette-only updater](../../Tools/update_proxy_palette_v07.py) changes and verifies existing material-instance parameters without reimporting geometry; the full importer uses the same values.

The first import rendered black proxies because an unchecked material link requested a nonexistent `RGB` pin from the Vertex Color node. UE 5.8 exposes that combined output without a name. Correcting the graph exposed another defect: Interchange had ignored the legacy FBX vertex-color setting and supplied white colors. The importer now explicitly uses the legacy FBX route, checks for nonwhite colors in the actual Unreal mesh, exports its source colors to ASCII FBX, and records decoded linear color minima/maxima/means. Every material connection is checked. The same revision fixes inward crown winding. These verified corrections do not establish that the distant silhouettes or performance are acceptable.

A later capture still showed pale crowns despite correct imported source colors. The exact runtime attribute discrepancy remains undiagnosed, so the material no longer relies on that channel for its base albedo. Source-mesh validation and rendered validation are separate requirements. UE 5.8's unattended atomic reimport also replaces task options with the existing mesh's stored import data; the importer now explicitly updates that data to replace vertex colors before reimporting. Quantitative source-color checks remain mandatory.

The original 836/656-triangle lobed crowns were rejected even after their colors were corrected: their smooth shapes looked artificial. The replacement geometry follows the actual source distribution. Blender [broadleaf](SM_BroadleafProxy_shape.png) and [conifer](SM_ConiferProxy_shape.png) previews expose its shape; the retained Shipping [ground](../Previews/v07_ground.png), [colony](../Previews/v07_colony.png), and [hills](../Previews/v07_hills.png) captures show the actual rendering. The editable grass scene contains only the grass mesh; the rejected tree objects were removed without altering grass geometry or its FBX hash.

## Authored near tree

[SM_JacarandaNearV07](jacaranda_lod1_manifest.json) is a separate derivative of Poly Haven's CC0 authored Jacaranda LOD1, with 1,845,603 source triangles versus the existing LOD0's 3,863,832. The [targeted generator](../../Tools/prepare_jacaranda_lod1_v07.py) preserves photographic UV/material mapping and matches the current tree's exact bounds and ground pivot. The [targeted importer](../../Tools/import_jacaranda_lod1_v07.py) reuses the existing three NatureV04 materials. The older tree asset is preserved. The [import report](jacaranda_lod1_import_report.json) verifies the new asset's dimensions, materials, and Nanite area preservation, and v0.7 uses it for both near broadleaf roles. Shipping measurements cover the whole revision; no isolated GPU saving is attributed to this tree, and alpha-mask cost remains. [Source and license](https://polyhaven.com/a/jacaranda_tree)

The [source inventory](jacaranda_source_lods.json) confirms only LOD0 and LOD1 complete trees. A [deterministic sampled leaf-coverage estimate](jacaranda_leaf_coverage.json) found approximately 43–50% of template triangle surface passing alpha 0.33. This estimates geometry's transparent surface area, not rendered GPU overdraw or an achievable speedup. It suggests a future true leaf-outline geometry experiment could be more useful here than the earlier grass trimming attempt.

Runtime near/far transforms share the same deterministic placement. Bounds extents and world-space bounds centers are aligned, including source-pivot offsets. Eight fixed per-instance distance bands spread the handoff over a region; they do not reduce instance density or turn alpha cards opaque. Tree placements use the full sector sequence at all focus levels, so changing the focused sector no longer introduces a separate sparse-to-dense tree layout.

Remaining risks are visible silhouette/color changes at the handoff, very fine grass coverage at native resolution, instance-memory cost for the larger resident area, and upload/removal costs beyond the soft streaming budget. Focus changes still rebuild scenery. The source contains no claim that these proxies match Manor Lords quality or guarantee a particular frame rate. The [v0.7 graphics report](../../docs/game-design/GRAPHICS_PERFORMANCE_0_7.md) separates measured results from these remaining limits.
